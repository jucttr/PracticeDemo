# 数组去重方式总结

对应源码：`index.js`（`unique` ~ `unique8` 共 8 个函数，外加一行展开写法，共 9 处代码）。

按**去重思路**归类，实际只有 5 类：

| 类别                      | 代表实现                                                            | 关键点 / 局限                                                                           |
| ------------------------- | ------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| 1. Set（ES6）             | `unique`、`[...new Set(arr)]`                                       | 最简洁，能处理 `NaN`；对象按引用区分，内容相同也去不掉                                  |
| 2. 遍历 + 结果集查找      | `unique2`(indexOf)、`unique5`(includes)、`unique8`(reduce+includes) | 同一套路，只是查找 API 不同：`indexOf` 用严格相等，去不掉 `NaN`；`includes` 可以        |
| 3. 双重循环 + splice      | `unique3`                                                           | ES5 最常用，原地删除；用了 `==`，会误删 `null`，`NaN` 也去不掉                          |
| 4. 对象属性名唯一（哈希） | `unique4`、`unique6`                                                | `unique6` 用 `typeof + item` 拼 key 区分类型；对象都会被转成 `[object Object]` 而误合并 |
| 5. filter + 首次索引      | `unique7`                                                           | 只保留「元素第一次出现的位置 == 当前索引」的项，`NaN` 去不掉                            |

> [!tip] 三个必记坑点
>
> -   **NaN**：`===` / `indexOf` 去不掉，`Set` / `includes` 能处理
> -   **对象引用**：内容相同也不会被认为是重复
> -   **类型混淆**：对象属性法会把 `1` 和 `'1'` 当成同一个 key

## 面试口述版

> [!note] 可直接回答面试官
> 这份代码写了 8 种去重函数，但按思路可以归成 5 类：

第一类是 ES6 的 `Set`，最简洁也最推荐；

第二类是遍历数组、在结果集里查找，`indexOf`、`includes`、`reduce` 都是同一思路的不同写法；

第三类是 ES5 常用的双重循环加 `splice` 原地删除；

第四类是利用对象属性名唯一做哈希，`filter` 拼 `typeof` 是它的改良版；

第五类是 `filter` 配合 `indexOf`，只保留首次出现的位置。选哪种主要看场景：数据里没有特殊类型、追求简洁就用 `Set`，要兼容老环境就用 `indexOf` 或双重循环。

要注意几个坑：`NaN` 用 `indexOf` 或 `===` 去不掉，但 `Set` 和 `includes` 可以；对象因为引用地址不同不会被当成重复，而用对象属性做哈希又会把不同对象误合并。
